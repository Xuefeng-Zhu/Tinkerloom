# Full AppSpec host entry points

`FullAppController({scope,transport,newId,adapterFactory?,onAccessFailure?})` owns an authenticated app lifetime. Inject the real account-fenced transport and cryptographic operation IDs. `adapterFactory` can supply the media/reminder implementation; the default is the frozen FunctionRuntimeAdapter. `FullAppScreen` receives this controller and navigation callbacks; optional `initialMode` opens a resumed draft directly in `build`. The account registry owns disposal, including when authentication expires. Navigation must not dispose unresolved journals or create another operation to bypass them.

`FullWorkspaceController({scope,workspaceId,transport,newId,onAccessFailure?})` owns the workspace launcher and its retained creation/remix/pin operation. `FullLauncher` receives full/classic app navigation callbacks and optional `onResumeDraft(id,engine)` for direct builder routing. Immutable inspection uses an isolated preview and does not represent historical live records.

The frozen host provides encrypted, scoped durable storage. Every mutating operation is saved with its exact original envelope before transport. Reopening reads recovery but does not replay. Explicit retry keeps the original operation, revisions, candidate and review scope. Only definitive rejection can be acknowledged. Successful historical receipts confirm outcome only; fresh permissions always come from a new authorized manifest read. A failed refresh keeps writes locked. True role loss hides private payloads without deleting an unresolved encrypted operation.

Visual declaration edits use validated semantic patches, atomic field/form bindings and stable allocated IDs. Text edits debounce 600 ms; discrete controls save immediately. Saving or an unknown/conflicting result locks further edits. Mode transitions flush valid pending text. Design mode renders the actual semantic components with a read-only adapter: selecting a component opens its inspector, and record execution is blocked. The interactive sample preview stays mounted across editing modes so presentation updates retain its data and navigation. The advanced JSON editor supplements visual fields, views, actions, pages, appearance and reminder controls.

Publication requires an authoritative exact candidate review and a separate user approval. Reminder effects default off and must be operational in platform capabilities. Existing record enrollment accepts exact live IDs and is validated by the server; no synthetic record IDs are transferred. Device permissions remain separate, local and off by default.

The isolated preview factory receives no authenticated adapter, encrypted store or device bridge. Strict presentation-only updates preserve sample records, receipts, cursors and navigation; a semantic change creates a fresh sample session. Runtime timers and device controls in the authenticated host use their app/account lifetime and release when leaving live mode.

Offline controller and preview tests validate recovery and lifecycle semantics. Provider execution, browser interaction of integrated routes, native modules and physical device behavior require their own verification; these tests are not proof of those layers.

Root integration now supplies account-scoped inbox/run services and operational
reminder adapters. Generic app and edit links resolve small access metadata
before choosing their engine. Runtime factories receive `{host,platform}` only
after capability negotiation; confirmed authority loss clears private state
before optional capability reads. Record changes preserve dirty forms; a new
published version remains outdated until the user resolves those edits. The
serviceWire fixture is generated by `appwrite_backend/test/export_client_wire.dart`
and compared in CI, rather than inventing a second client-only wire contract.

Live activity uses removable focus leases. Retained background navigation routes
cannot keep polling or device controls active, and an old route cleanup cannot
pause a newer focused route. Native device foreground observation and scoped
watch activity handle OS backgrounding separately. Trusted watch stamps reach the
app host before record refresh, so role/archive changes clear private state even
while a record form is dirty.
